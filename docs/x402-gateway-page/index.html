x402 · XRP Ledger · non-custodial

Accept & make payments over HTTP, on XRPL.

The x402 Gateway for XRPL lets any project take x402 payments with no server to deploy — register a project, set where funds go and how much, share your endpoint. Agents and apps pay it directly. Funds settle payer → your wallet; the gateway never holds funds or keys.

Quickstart

Projects register a projectId + payTo + price. Payers just hit the endpoint.

# Project config (registry) — where funds go & how much
{ "projectId": "demo-tips", "payTo": "r…",
  "asset": { "code": "XRP" }, "price": { "mode": "range", "min": 0.1, "max": 100 } }

# Payer — pay the project's endpoint
node pay.mjs https://xrpdomains.xyz/mcp/x402/pay/demo-tips

Same rails already proven live on XRPL mainnet — an AI agent registered xrpl-x402.xrp autonomously: receipt.
